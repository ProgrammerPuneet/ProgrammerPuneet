## About me

I am a **Software Engineer at Microsoft** working on reliability and intelligent automation for large-scale cloud systems. Previously, I was a **Software Engineer II at Walmart Global Tech**, building high-performance backend platforms and reusable distributed-system components.

- I build production systems with **Java, Python, Spring Boot, cloud infrastructure, and AI/LLM orchestration**.
- I enjoy designing **scalable APIs, concurrent services, retrieval systems, and developer platforms**.
- My work has been recognized with the **Microsoft Pinnacle FY26** and **Walmart Exemplary (top 1%)** awards.
- Away from production systems, I explore system design, optimization algorithms, and practical AI engineering.
